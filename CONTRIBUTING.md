# Contributing to RepoTestUse

This is a public, documentation-oriented example repository.

1. Create a feature branch and make a focused change.
2. Describe the intended behavior, source documentation, and evidence of any actual tool/test execution.
3. Distinguish placeholders, illustrative snippets, and verified results.
4. Do not commit credentials, customer/payment data, private repository content, internal endpoints, or secret-bearing logs.
5. Request review in a pull request. Do not assume that repository write access authorizes bypassing branch governance or merging.

Changes that enable live network integration, permissions, security policies, or deployment automation require their own scoped review and authorization.
