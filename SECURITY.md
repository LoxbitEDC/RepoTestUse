# Security policy for RepoTestUse

This repository is public and contains **non-production examples**. Treat all committed content as publicly visible.

For security concerns or accidentally published sensitive information, contact repository maintainers privately through an authorized channel. Do not include credentials, customer data, exploit payloads, or internal system details in public GitHub issues.

No production security guarantees are claimed by the current sample MCP configuration or placeholder CI workflow. Security review and live verification are required before any operational deployment.
